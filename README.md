🎓 ScholarPath AI

ScholarPath AI is an AI-powered scholarship recommendation system designed to help students discover eligible government and private scholarships based on their academic profile, category, income, and gender.

The system uses Google Gemini AI to generate personalized scholarship guidance, document checklists, and application tips.

---

# 🚀 Features

✅ AI-powered scholarship recommendation  
✅ Personalized eligibility matching  
✅ Smart scholarship ranking system  
✅ Gemini AI integration  
✅ Document guidance and expert tips  
✅ Gender/category/income-based filtering  
✅ Official scholarship portal links  
✅ Input validation and error handling


# 🧠 How It Works

The system:

1. Takes student details:
   - State
   - Category
   - Income
   - CGPA
   - Gender

2. Filters matching scholarships.

3. Ranks scholarships using:
   - Financial benefit
   - CGPA suitability

4. Sends student profile to Gemini AI.

5. Generates:
   - Personalized guidance
   - Required document checklist
   - Scholarship tips
   - Official links
